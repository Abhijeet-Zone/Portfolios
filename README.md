## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18.17 or higher) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Abhijeet-Zone/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   *(Utilizing Turbopack for faster HMR)*
   ```bash
   npm run dev
   ```

4. **View the site:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Building for Production

To create an optimized production build of the portfolio:

```bash
# Compile and optimize the application
npm run build

# Start the production server
npm run start
```
*Note: All pages are successfully pre-rendered as static HTML for maximum performance.*
